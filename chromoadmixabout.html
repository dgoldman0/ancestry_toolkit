About the Chromosome Admixture Metrics

Human genomes are mosaics of ancestry. Chromosomes are inherited in blocks that get broken down by recombination each generation. Admixture analysis tries to detect what proportion of DNA in a person traces back to different reference populations. Projects like Eurogenes (and other calculators built on ADMIXTURE or similar software) attempt to quantify this.

Traditionally, admixture is summarized as a single proportion per population (for example, "20% North Atlantic"). Chromosome-by-chromosome output adds another layer: it shows whether a component is broadly distributed or concentrated on a few chromosomes. The drawback is data explosion. Instead of one number per population, there are up to 22 chromosome values per population.

This tool reduces those values into Mean, Pulse, Stability, Residual Stability, and Sparsity. These metrics are descriptive summaries of between-chromosome distribution. They do not recover tract length, exact admixture dates, or literal ancestry segments.

Why Chromosome-Level Matters

Recombination, inheritance randomness, drift, reference-panel overlap, and calculator noise can all affect chromosome-level values. A broad component and a narrow component can have the same total Mean but very different shapes across chromosomes. The metrics below summarize that shape while keeping the results comparable within a pasted dataset.

Weighted Mean and CV

Chromosomes differ in length. When weighting is enabled, SNP counts are used as chromosome-length proxies for Mean, variance, CV, and Top-n Mean:

\[ W = \sum_{i=1}^{22} w_i,\quad \mu_w = \frac{\sum_i w_i x_i}{W},\quad \mathrm{CV}_w = \frac{\sqrt{\sum_i w_i(x_i - \mu_w)^2/W}}{\mu_w} \]

where \(x_i\) is the percentage for chromosome \(i\), and \(w_i\) is its SNP count. Sparsity remains based on the displayed chromosome percentages.

Pulse

Pulse measures excess top-chromosome concentration. First define the spike ratio:

\[ R = \frac{\mathrm{TopNMean}}{\mu} \]

A perfectly even row has \(R = 1\), so the current Pulse formula subtracts that baseline:

\[ \mathrm{Pulse} = \frac{R - 1}{\log_2(100/\mu)} \]

The denominator is a dilution-inspired scale adjustment. It helps keep tiny mean components from looking overly dramatic when one chromosome is elevated. It is not a generation-count estimate.

Stability

Stability is the chart's default Y-axis. It measures raw chromosome-level smoothness from the coefficient of variation:

\[ \mathrm{Stability} = -\log(\mathrm{CV} + \epsilon) \]

Higher Stability means lower relative variation across chromosomes. This is intentionally kept as a raw smoothness axis because broadness and magnitude can both be part of the ancestry signal.

Residual Stability

Residual Stability is a secondary diagnostic. It asks whether a component is smoother or spikier than expected for its overall Mean. The tool fits Stability against log Mean:

\[ \mathrm{Stability} = a + b\log(\mu + \epsilon) + e \]

The residual \(e\) is the Residual Stability value. Positive residuals are smoother than expected for the component's Mean; negative residuals are spikier than expected. With fewer than four usable population rows, the tool falls back to raw Stability because the regression is not stable enough. Residual Stability can also be selected as the chart's Y-axis.

Sparsity

Sparsity uses Hoyer sparsity on chromosome percentages:

\[ \mathrm{Sparsity} = \frac{\sqrt{n} - \left(\lVert x\rVert_1 / \lVert x\rVert_2\right)} {\sqrt{n} - 1} \]

Low Sparsity means the component is spread broadly. High Sparsity means the component is concentrated on fewer chromosomes.

Yeo-Johnson Standardization

Pulse, Stability, Residual Stability, and Sparsity can be skewed. Some can also be zero or negative, so the tool uses a Yeo-Johnson transformation followed by z-scoring:

\[ z = \frac{T_\lambda(x) - \overline{T_\lambda(x)}}{\mathrm{SD}(T_\lambda(x))} \]

These z-scores are relative to the pasted dataset. They are useful for comparing components within one run, not for making universal absolute claims.

Chart Encoding

The scatter plot encodes each ancestry component as:

\[ \begin{cases} x = \mathrm{Pulse\ Score} \\\\ y = \mathrm{Stability\ Score\ or\ Residual\ Stability\ Score} \\\\ \mathrm{bubble\ size} = \mathrm{Mean} \\\\ \mathrm{color} = \mathrm{Sparsity\ Score} \end{cases} \]

The Y-axis control switches between raw Stability Score and Residual Stability Score. The label controls can show all labels, hide labels, or show labels only above the low-signal cutoff. Components below that cutoff are drawn as open circles. The chart can also filter by minimum Mean, show only the largest Mean components, display optional quadrant hints, and export a higher-resolution PNG. The plot pads the axes and allows labels to render beyond the axis box so edge points are less likely to be clipped.

Encrypted Workspace Files

Workspace saving is manual. The app does not autosave, and it does not store workspaces in localStorage, sessionStorage, or IndexedDB. A workspace can hold multiple kits in a visible .chromoworkspace file.

In browsers with file-handle support, Open Workspace and Save As associate the current workspace with that file, so later Save writes back to it without opening another file picker. Other browsers fall back to encrypted downloads.

The workspace payload includes the workspace name, the active kit, and each kit's parsed results, analysis settings, and chart settings. The Visible kit selector swaps which kit is shown in the paste box, tables, and chart. New, rename, duplicate, and delete update the in-memory workspace until the next manual save. This first multi-kit view does not perform cross-kit comparison; it only switches the visible analysis.

Raw input is tracked per kit and is included only when Include raw paste is enabled for that kit; parsed results are saved either way. Loaded single-kit workspace files from the earlier format are treated as one-kit workspaces.

Workspace contents are encrypted in the browser using AES-GCM with a 256-bit key derived from the passphrase using PBKDF2-HMAC-SHA-256 with 650,000 iterations. Each save uses a fresh random salt and IV. Wrong passphrases or tampered files fail to decrypt. The app cannot recover a forgotten passphrase.

Uses and Limitations

Uses: The metrics help flag broad, smooth, top-heavy, and sparse chromosome-level patterns that may be worth comparing against family history, other calculators, or segment-level tools.

Limitations: Calculator components are estimates, not direct ancestry segments. Closely related reference populations can move together. Low-Mean components are especially vulnerable to noise. Per-chromosome summaries cannot recover tract lengths or exact admixture dates.

In short, the tool turns a large chromosome-by-chromosome table into a compact description of distribution shape: how much signal is present, whether it is top-heavy, whether it is smooth, whether it is unusually smooth for its Mean, and whether it is concentrated on few chromosomes.
